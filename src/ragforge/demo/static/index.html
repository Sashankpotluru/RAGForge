Retrieval architecture

Follow a question through dense retrieval, lexical matching and optional reranking to its cited passages.

Each query searches the sample collection. Hybrid retrieval fuses dense and lexical rankings. The optional reranker scores those candidates again. The local model extracts an answer from the retrieved passages. The service attaches a citation when the generated words match a single passage.
